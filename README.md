# Fedora T7 Backup

Activity 684219 operates an encrypted, deduplicated Restic backup of Fedora
to the Samsung drive called simply **T7**. Fedora identifies the physical T7 by
model `Samsung PSSD T7 Shield`, serial `S6YGNS0Y903440H`, filesystem UUID
`4c75ac03-4c73-43f8-afd9-f90db49a74fc`, label `T7_BACKUP`, and mount
`/mnt/T7_BACKUP`.

Start with [operations](docs/human/OPERATIONS.md) and the
[activity 684219 report](docs/human/REPORT_684219.md). No credential or backed-up
content is stored in Git.
